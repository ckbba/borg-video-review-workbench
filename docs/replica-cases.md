# 一键复刻 · 案例记录

## 2026-11-05 安踏 C202 6代 PRO / Nike Air More Uptempo 换鞋（任务 20261105-062f71、20261105-be1e97）

原片：系鞋带的 11.8 秒竖屏，先正面再侧面抬脚，白色阿迪达斯运动鞋。MiniMax H3 768p，保留原声，各 35.30 元（含一次自动重做）。

**结果**：颜色和整体风格到位，但鞋面结构不对。安踏买家秀显示真实鞋面是白色飞织，前掌侧面有一大块分层中底；成片把橙红鞋底拉成了一长条，侧面的安踏标志也变了形。Nike 的 AIR 字母排列错了，开头白布滑走的镜头被模型跳过。

**原因**：用户只给了一张 3/4 角度的宣传图，原片却要正面、侧面、抬脚这几个角度。联网找来的图多半是别的配色，AI 拿它合成的三视图细节不符，验收没通过，没被采用；结果看不到的角度只能靠模型推测。

**结论**
- 用户没给够角度时，不追求和真实商品一模一样，优先保证视频帧里的动作、构图和节奏照原片来。
- 给用户解释清楚，并引导多上传几个角度。例如这张买家秀（侧面 + 鞋底）就够还原这条片子。
- 联网找到的图只拿来看形状，配色不能用；三视图合成不可靠时，宁可不用。

**待做**
- 上传页按原片需要的角度提示用户补图（"原片有侧面和鞋底，建议补一张"）。
- 质检不过时，判断重做能改善才自动重做，或者先问用户（这两条各白花了 17.40 元）。
- 原片里有遮挡揭开这类开场动作的，要单独约束。

### 续：同一双安踏，补了 3 张实拍角度图（任务 20261105-44ead2，480p，原片风格 + 动画风，26.33 元）

侧面明显变好了，大块橙红中底和后跟都对。但 AI 生成的三视图有两处错误，验收却放过了：
- 内侧画上了蓝色飞线，真鞋只有外侧有。
- 编造了实拍图里没有的纹理细节。

**原因**：我把验收放宽成了"看不到的角度合理即可"，验收时也没把实拍角度图一起对比。

**改进**
- 实拍图加起来够 3 张时（用户的图 + 补充角度图），不再生成三视图，实拍图直接用来做关键画面。
- 三视图里看不到的那一侧只画素面，不能照搬另一侧的图案。
- 验收时把每张实拍图都拿来对比；只要出现实拍图里没有的线条、图案、纹理就不通过。关键画面的验收标准也同样收紧。
